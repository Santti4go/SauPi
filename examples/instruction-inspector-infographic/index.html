02 · ANATOMÍA DEL INVENTARIO

“Descubierto” no significa “leído”.

SYSTEM

System + role prompt

Busca SYSTEM.md, APPEND_SYSTEM.md, flags CLI y PI_ORCHESTRATOR_ROLE_PROMPT_PATH. Los candidatos no explícitos se validan contra customPrompt o appendSystemPrompt.

CONTEXT

Context files exactos

Usa directamente options.contextFiles[].path. Aquí aparecen los AGENTS.md que Pi concatenó, no todos los que existen en el repositorio.

SKILL META

Skills anunciadas

Pi agrega nombre, descripción y path al prompt cuando read está activo. Se excluyen las skills con disableModelInvocation.

SKILL BODY

Skills efectivamente leídas

El hook tool_result registra un read exitoso si coincide con una skill anunciada o con un archivo llamado SKILL.md.

Regla mental: la metadata de una skill puede estar en el system prompt; el cuerpo de SKILL.md entra al contexto conversacional sólo después de leer el archivo.

04 · CONTRATO TÉCNICO

Qué ocurre al ejecutar /instructions watch

  1. 01

    Alterna un booleano local

    widgetVisible = !widgetVisible. El estado vive en la instancia de la extensión.

  2. 02

    Reutiliza el snapshot más reciente

    No dispara un turno del agente. En versiones con getSystemPromptOptions(), el comando puede obtener opciones actuales; de lo contrario usa el snapshot capturado en el primer prompt.

  3. 03

    Actualiza exclusivamente la TUI

    ctx.ui.setWidget("instruction-inspector", lines) muestra el panel; una segunda invocación pasa undefined y lo elimina.

  4. 04

    Limpieza garantizada

    session_shutdown elimina status y widget para no dejar UI residual durante reload, resume o cierre.
